Recommended k-Wave core
=======================

The recommended core for the xDDx heterogeneous simulator is the forked,
memory-saving k-Wave implementation available at:
https://github.com/pavrosni/k-wave

Fork modifications Copyright (C) 2026 Pavel Rosnitskiy.

This fork provides memory-saving support for single-frequency simulations.
Upstream k-Wave project: https://www.k-wave.org/
